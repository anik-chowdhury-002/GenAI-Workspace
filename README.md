# GenAI-Workspace
Welcome to my personal Generative AI Workspace! This repository serves as a practical sandbox and playground for experimenting with cutting-edge Large Language Model (LLM) orchestration frameworks, Agentic workflows, Retrieval-Augmented Generation (RAG) systems, and Model Context Protocol (MCP).

🛠️ Tech Stack & Core Concepts
Python (Core Development)

LangChain & LangGraph (Agentic Workflows & LLM Orchestration)

RAG Pipelines (Advanced Information Retrieval & Generation)

MCP (Model Context Protocol) (Context integration and tool use)

Jupyter Notebooks (Interactive experimentation and prototyping)


1. Clone the Repository
Bash
git clone https://github.com/anik-chowdhury-002/GenAI-Workspace.git
cd GenAI-Workspace
2. Create and Activate a Virtual Environment
Bash
python -m venv venv
# On Windows (PowerShell):
.\venv\Scripts\Activate
3. Install Dependencies
Bash
pip install -r requirements.txt
